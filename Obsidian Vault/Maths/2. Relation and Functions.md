## 🔷 SECTION 1: CARTESIAN PRODUCT OF TWO SETS

### 1.1 Definition

Given two sets $A$ and $B$, the **Cartesian Product** $A \times B$ is the set of **all possible ordered pairs** $(a, b)$ where the first element comes from $A$ and the second comes from $B$.

$$A \times B = {(a, b) : a \in A \text{ and } b \in B}$$

**Worked Example:** $$A = {1, 2}, \quad B = {3, 4, 5}$$ $$A \times B = {(1,3),(1,4),(1,5),(2,3),(2,4),(2,5)}$$

### 1.2 $A \times B \neq B \times A$ (Not Commutative)

$$B \times A = {(b,a) : b \in B \text{ and } a \in A}$$

**Worked Example (continued):** $$B \times A = {(3,1),(3,2),(4,1),(4,2),(5,1),(5,2)}$$

Clearly $A \times B \neq B \times A$ — the ordered pairs are reversed, and (except in special cases) represent entirely different pairs.

**⚠️ Special Case:** If $A = \emptyset$ or $B = \emptyset$ or both, then $A \times B = B \times A = \emptyset$.

### 1.3 Number of Elements in a Cartesian Product

$$n(A \times B) = n(A) \times n(B)$$

**Worked Example:** $A = {1,2,3}$, $B = {x,y}$, so $n(A)=3$, $n(B)=2$. $$n(A \times B) = 3 \times 2 = 6$$ Verify: $A \times B = {(1,x),(2,x),(3,x),(1,y),(2,y),(3,y)}$ — exactly 6 pairs. ✔️

### 1.4 Cartesian Product with Set Operations (Distributive-Style Identities)

These behave like a distributive law, and are a favorite "verify" question:

$$A \times (B \cup C) = (A \times B) \cup (A \times C)$$ $$A \times (B \cap C) = (A \times B) \cap (A \times C)$$ $$A \times (B - C) = (A \times B) - (A \times C)$$ $$(A \cap C) \times B = (A \times B) \cap (C \times B)$$

**Worked Example (verify $A \times (B - C) = (A\times B)-(A\times C)$):** $$A = {4,5,6,7}, \quad B = {8,9}, \quad C = {10}$$ $B - C = {8,9}$ (10 isn't in B, nothing removed) LHS: $A \times (B-C) = {(4,8),(4,9),(5,8),(5,9),(6,8),(6,9),(7,8),(7,9)}$ $A \times B = {(4,8),(4,9),(5,8),(5,9),(6,8),(6,9),(7,8),(7,9)}$ $A \times C = {(4,10),(5,10),(6,10),(7,10)}$ RHS: $(A\times B)-(A\times C)$ — since $A\times C$ has no pairs with 8 or 9, nothing is removed, RHS = same set as $A\times B$. LHS = RHS ✔️ **Verified.**

### 1.5 Cartesian Product of a Set with Itself — Ordered Triplets

$$A \times A \times A = {(a,b,c) : a,b,c \in A}$$

**Worked Example:** $A = {1,2}$ $$A\times A\times A = {(1,1,1),(1,1,2),(1,2,1),(1,2,2),(2,1,1),(2,1,2),(2,2,1),(2,2,2)}$$

$\mathbb{R} \times \mathbb{R}$ represents all points $(x,y)$ in a 2D plane; $\mathbb{R}\times\mathbb{R}\times\mathbb{R}$ represents all points $(x,y,z)$ in 3D space.

## 🔷 SECTION 2: RELATIONS

### 2.1 Definition

If $A$ and $B$ are two sets, a **relation** $R$ from $A$ to $B$ is any **subset** of $A \times B$.

$$R \subseteq A \times B, \quad \text{i.e., } R = {(a,b) : a\in A, b\in B, \text{ and } aRb}$$

**Worked Example (brother relation):** $A={\text{Mohan, Sohan, David, Karim}}$, $B={\text{Rita, Marry, Fatima}}$, relation "is a brother of": $$R = {(\text{Mohan, Rita}),(\text{Sohan, Rita}),(\text{David, Marry}),(\text{Karim, Fatima})}$$

### 2.2 Types of Relations (by structure)

|Type|Condition|
|---|---|
|Void (Empty) Relation|$R = \emptyset$|
|Universal Relation|$R = A \times B$|
|Relation on A|$R$ defined from $A$ to $A$ (i.e. $R \subseteq A\times A$)|
|Identity Relation|$R = {(a,a) : \forall a \in A}$|

### 2.3 Domain, Range, and Co-domain of a Relation

- **Domain** = set of **all first elements** of the ordered pairs in $R$.
- **Range** = set of **all second elements** of the ordered pairs in $R$.
- **Co-domain** = the entire set $B$ (the "target" set), regardless of which elements actually get used.

**Key Fact:** $$\text{Range} \subseteq \text{Co-domain}$$ (Range only includes values that actually appear; co-domain is the whole set B they're drawn from.)

**Worked Example:** $A={2,4,5,6,7}$, $B={2,3}$, $R={(a,b): a\in A, b\in B, a \text{ is divisible by } b}$

- Roster form: $R = {(2,2),(4,2),(6,2),(6,3)}$
- Domain of $R = {2,4,6}$
- Range of $R = {2,3}$
- Co-domain of $R = B = {2,3}$ (given, whole set)

**Worked Example (co-domain ≠ range):** $A={1,3,4,5,7}$, $B={2,4,6,8}$, relation "is one less than": $$R = {(1,2),(3,4),(5,6),(7,8)}$$ Co-domain of $R = {2,4,6,8}$ (this happens to equal the range here, but doesn't always — see Section 3 for a case where it doesn't).

## 🔷 SECTION 3: DEFINITION OF A FUNCTION

### 3.1 Core Definition

A relation $f$ from set $A$ to set $B$ is called a **function** if **every element of $A$ has a UNIQUE image in $B$**.

$$f : A \to B \quad \text{or} \quad A \xrightarrow{f} B$$

**Two conditions must BOTH hold for a relation to be a function:**

1. **Every element of $A$ must appear** as a first element (nothing in $A$ is left out).
2. **No element of $A$ repeats** with two different second elements (each input has exactly ONE output).

> 💡 **In a function, no two ordered pairs have the same first element.**

**Worked Example (function, co-domain ≠ range):** $f = {(a,1),(b,2),(c,3),(d,5)}$ from $A={a,b,c,d}$ to $B={1,2,3,4}$.

- Every element of $A$ has a unique image → **it IS a function**.
- Co-domain $= B = {1,2,3,4}$
- Range $= {1,2,3,5}$ (4 has no preimage in $A$, so it's in the co-domain but NOT in the range)
- **Conclusion:** Range is a subset of co-domain, but need not equal it.

### 3.2 Real Valued Function of a Real Variable

If $X, Y$ are non-empty subsets of $\mathbb{R}$, a rule $f$ that associates to each $x \in X$ a **unique** $y \in Y$ is called a **real function**, written $f: X \to Y$.

### 3.3 The "Is It a Function?" Checklist — With Worked Examples

For a relation given as a **set of ordered pairs**, ask: (1) Does every element of A appear as a first element? (2) Does no first element repeat?

|Relation|A|B|Function?|Reason|
|---|---|---|---|---|
|${(1,-2),(3,7),(4,-6),(8,1)}$|${1,3,4,8}$|—|✔️ Yes|Domain = A exactly, no repeats|
|${(1,0),(1,-1),(2,3),(4,10)}$|${1,2,4}$|—|❌ No|First two pairs share first element (1 maps to 0 AND -1)|
|${(a,b),(b,c),(c,b),(d,c)}$|${a,b,c,d,e}$|${b,c}$|❌ No|Domain $={a,b,c,d} \neq A$ (element $e$ has no image)|
|${(2,4),(3,9),(4,16),(5,25),(6,36)}$|${2,3,4,5,6}$|—|✔️ Yes|Every element has a unique image|
|${(a,b),(a,2),(b,3),(b,4)}$|${a,b}$|—|❌ No|Both $a$ and $b$ repeat with different second elements|

**For relations given by an inequality/equation (e.g. from $\mathbb{R} \to \mathbb{R}$):**

The test is: _"For every real x, does the rule give exactly ONE real y?"_

|Relation|Function?|Reason|
|---|---|---|
|$y = 3x+2$|✔️ Yes|Every $x$ gives exactly one $y$|
|$y < x+3$|❌ No|Every $x$ gives infinitely many valid $y$ values (an inequality, not an equation)|
|$y = 2x^2+1$|✔️ Yes|Every $x$ gives exactly one $y$ (squaring then adding 1 is single-valued)|

**For relations given as arrow diagrams:**

|Diagram Pattern|Function?|Reason|
|---|---|---|
|Some element of A has NO arrow out|❌ No|Violates "every element must have an image"|
|Some element of A has TWO arrows out (to different elements of B)|❌ No|Violates "unique image" — one input, two outputs|
|Every element of A has exactly ONE arrow out|✔️ Yes|Both conditions satisfied|
|Two elements of A point to the SAME element of B|✔️ Yes (still valid)|This is fine — many-to-one is allowed. Only one-to-many breaks it.|

> 💡 **Golden Rule:** Many-to-one is OK for a function (many inputs can share one output). One-to-many is NEVER OK (one input cannot have two outputs).

### 3.4 Evaluating a Function at a Point

If $f(x) = 2x+1$, then $f(1) = 2(1)+1 = 3$, $f(2)=2(2)+1=5$, etc. Simple substitution.

## 🔷 SECTION 4: DOMAIN AND RANGE — WORKED TECHNIQUES

### 4.1 Why Domain Restrictions Exist

Domain = the set of all $x$ values for which $f(x)$ is **actually defined** (produces a real, valid output). Two things break real-valuedness:

- **Division by zero** (denominator = 0 is undefined)
- **Square root (or even root) of a negative number** (not real)

### 4.2 Rational Functions — $y = \dfrac{1}{x - a}$ type

**Rule:** Exclude the value(s) of $x$ that make the denominator zero.

**Worked Example:** $y = \dfrac{1}{x-2}$ Denominator zero when $x=2$. **Domain $= \mathbb{R} - {2}$**

**Worked Example (factored denominator):** $y = \dfrac{1}{(x+2)(x-3)}$ Denominator zero when $x=-2$ or $x=3$. **Domain $= \mathbb{R} - {-2, 3}$**

### 4.3 Square Root Functions — Single Term: $y = \sqrt{x-a}$ type

**Rule:** Whatever is inside the root must be $\geq 0$ (0 is allowed since $\sqrt{0}=0$ is valid).

**Worked Example:** $y = \sqrt{x-2}$ Need $x - 2 \geq 0 \Rightarrow x \geq 2$. **Domain $= [2, \infty)$**

### 4.4 Square Root Functions — Product of Two Factors: $y=\sqrt{(a-x)(b+x)}$ type

**Rule:** Need $(\text{factor}_1)(\text{factor}_2) \geq 0$. This happens when **both factors are positive, or both are negative**. Use the **zone-testing method**:

**Step-by-step method (memorize this):**

1. Find the critical points — where each factor individually equals zero.
2. These points split the number line into zones.
3. Test one value from each zone in the original product.
4. Keep only the zones where the product is $\geq 0$.

**Worked Example:** $y = \sqrt{(2-x)(4+x)}$ Critical points: $2-x=0 \Rightarrow x=2$; $\ 4+x=0 \Rightarrow x=-4$ Zones: (i) $x<-4$, (ii) $-4<x<2$, (iii) $x>2$ Test $x=-10$ (zone i): $(2-(-10))(4+(-10)) = (12)(-6) = $ negative Test $x=-1$ (zone ii): $(2-(-1))(4+(-1)) = (3)(3) = $ positive Test $x=3$ (zone iii): $(2-3)(4+3) = (-1)(7) = $ negative Only zone (ii) gives $\geq 0$. **Domain $= [-4, 2]$** (endpoints included since equality is allowed)

**Worked Example (opposite pattern — outer zones positive):** $y=\sqrt{(x-3)(x+5)}$ Critical points: $x=3$, $x=-5$. Zones: $x<-5$, $-5<x<3$, $x>3$ Test $x=-10$: $(-13)(-5) = $ positive Test $x=0$: $(-3)(5) = $ negative Test $x=10$: $(7)(15) = $ positive Zones (i) and (iii) work, zone (ii) doesn't. **Domain $= (-\infty,-5] \cup [3,\infty)$** — a **two-piece** domain, joined with "or", NOT a single continuous range!

> ⚠️ **Critical Insight:** Whether the domain is ONE continuous interval or splits into TWO separate pieces depends entirely on which zones test positive — always test all zones, never assume the pattern from a previous question repeats.

### 4.5 Reciprocal-of-a-Root Functions: $y = \dfrac{1}{\sqrt{x-a}}$ type

**Rule:** Combine BOTH the root rule (inside $\geq 0$) AND the denominator rule (whole denominator $\neq 0$). Since $\sqrt{0}=0$ would make the denominator zero, the boundary point itself gets **excluded** here (unlike a plain square root, where it's included).

**Worked Example:** $y = \dfrac{1}{\sqrt{x-5}}$ Root needs $x-5\geq 0 \Rightarrow x\geq 5$. But denominator can't be 0, so $x\neq 5$ too. **Domain $= (5, \infty)$** — note the **round bracket**, unlike a plain root which would use a square bracket.

**Combined-condition Worked Example:** $y=\dfrac{1}{\sqrt{x}-2}$ Root needs $x \geq 0$. Denominator zero when $\sqrt{x}=2 \Rightarrow x=4$, so exclude $x=4$. **Domain $= [0,\infty) - {4} = [0,4)\cup(4,\infty)$**

### 4.6 Domain-Finding Method Bank — Master Table

|Function Pattern|Rule to Apply|Example Domain Result|
|---|---|---|
|$y=\dfrac{1}{x-a}$|Denominator $\neq 0$|$\mathbb{R}-{a}$|
|$y=\dfrac{1}{(x-a)(x-b)}$|Both factors $\neq 0$|$\mathbb{R}-{a,b}$|
|$y=\sqrt{x-a}$|Inside $\geq 0$|$[a,\infty)$|
|$y=\sqrt{a-x}$|Inside $\geq 0$ (flips inequality)|$(-\infty,a]$|
|$y=\sqrt{(a-x)(b+x)}$, single continuous zone|Product $\geq 0$, zone test|$[-b,a]$ style closed interval|
|$y=\sqrt{(x-a)(x-b)}$, outer zones work|Product $\geq 0$, zone test|$(-\infty,\min]\cup[\max,\infty)$ style two-piece|
|$y=\dfrac{1}{\sqrt{x-a}}$|Inside $>0$ strictly (combines both rules)|$(a,\infty)$|
|$y = x^2, x^3$, any pure polynomial|No restriction|$\mathbb{R}$|
|$y=\lvert x-a\rvert$|No restriction|$\mathbb{R}$|

### 4.7 Range-Finding Techniques

**Method A — Extremes/Boundary Substitution (for simple shifted/scaled roots):** Find the min and max of the domain, plug into the function, and track how the transformations (shift, scale, sign) affect the output.

**Worked Example:** $y = \sqrt{x+3}+2$, domain $=[-3,\infty)$ At $x=-3$ (min of domain): $y=\sqrt{0}+2=2$ → this is the **minimum** of range. As $x\to\infty$: $y\to\infty$ (no upper bound). **Range $=[2,\infty)$**

**Worked Example (double-root, closed domain):** $y=\sqrt{9-x^2}$, domain $=[-3,3]$ At $x=0$ (middle): $y=\sqrt{9}=3$ → **maximum**. At $x=\pm3$ (edges): $y=\sqrt{0}=0$ → **minimum**. **Range $=[0,3]$**

**Method B — Solve-for-x Method (for rational functions like $y=\dfrac{ax+b}{cx+d}$):** Rearrange the equation to isolate $x$ in terms of $y$. Whatever value of $y$ makes the new denominator zero is the value $y$ can **never** be — that's the excluded point in the range.

**Worked Example:** $y = \dfrac{x+2}{x-3}$ $y(x-3) = x+2 \Rightarrow yx - 3y = x+2 \Rightarrow yx - x = 2+3y \Rightarrow x(y-1) = 2+3y \Rightarrow x = \dfrac{2+3y}{y-1}$ Denominator zero when $y=1$ → $y$ can never equal 1. **Range $= \mathbb{R}-{1}$**

**Method C — Discriminant Method (for rational functions like $y=\dfrac{x^2}{x+1}$, where x appears squared):** Rearrange into a quadratic **in $x$** (treating $y$ as if it were a constant), then require the discriminant $D = b^2-4ac \geq 0$ (since $x$ must be real). Solve the resulting inequality in $y$ using the zone-testing method.

**Worked Example:** $y=\dfrac{x^2}{x+1}$ $y(x+1)=x^2 \Rightarrow x^2 - yx - y = 0$ Matching $ax^2+bx+c=0$: $a=1,\ b=-y,\ c=-y$ $D = b^2-4ac = y^2-4(1)(-y) = y^2+4y$ Need $D\geq0$: $y^2+4y\geq0 \Rightarrow y(y+4)\geq0$ Zone-test (critical points $y=0,\ y=-4$): this requires the same testing method as Section 4.4. **(Requires completing quadratics chapter first for full confidence — flagged for later revision.)**

> 💡 **Discriminant refresher:** For $ax^2+bx+c=0$: $D=b^2-4ac$. If $D\geq0$, real solutions exist. If $D<0$, no real solutions exist. **Common slip:** $(-y)^2 = y^2$, NOT $-y$ — always square away the negative sign fully.

## 🔷 SECTION 5: GRAPHICAL REPRESENTATION OF FUNCTIONS

### 5.1 The Vertical Line Test

Since any function can be represented as a set of ordered pairs, it can always be graphed. To check if a graph represents a function:

> 💡 **Vertical Line Test:** If any line drawn **parallel to the y-axis** cuts the graph in **more than one point**, the graph does NOT represent a function.

**Worked Example (parabola $y=x^2$):** A vertical line at any $x$-value crosses the curve exactly once → **IS a function**.

**Worked Example (circle $x^2+y^2=25$):** A vertical line through the middle of the circle crosses it at TWO points (e.g., at $x=3$: both $y=4$ and $y=-4$ satisfy the equation) → **NOT a function**.

### 5.2 Why This Test Works

A vertical line represents "all points with one fixed $x$-value." If it crosses the graph more than once, that means **one $x$-value maps to more than one $y$-value** — which directly violates the "unique image" rule for functions.

## 🔷 SECTION 6: SPECIAL FUNCTIONS

### 6.1 Monotonic Function

A function $F:A\to B$ is **monotonic on an interval $(a,b)$** if it is _either_ entirely increasing _or_ entirely decreasing on that interval.

**Increasing on $(a,b)$:** $$x_1 < x_2 \implies F(x_1) < F(x_2) \quad \forall\ x_1,x_2\in(a,b)$$ **Decreasing on $(a,b)$:** $$x_1 < x_2 \implies F(x_1) > F(x_2) \quad \forall\ x_1,x_2\in(a,b)$$

**Worked Example ($f(x)=x^2$, not globally monotonic, but monotonic on sub-intervals):** On $[0,\infty)$: increasing → monotonic here. On $(-\infty,0)$: decreasing → monotonic here too. But over the WHOLE domain $\mathbb{R}$, it is **NOT** monotonic (it changes direction at $x=0$).

**Worked Example ($f(x)=x^3$, globally monotonic):** For all $x_1<x_2$ in $\mathbb{R}$, $F(x_1)<F(x_2)$ always. **Monotonic on the entire domain $\mathbb{R}$.**

### 6.2 Even Function

$$F(-x) = F(x) \quad \text{for every } x \text{ in the domain}$$

**Worked Examples:**

- $F(x)=x^2$: $F(-x)=(-x)^2=x^2=F(x)$ ✔️ Even
- $F(x)=\cos x$: $F(-x)=\cos(-x)=\cos x=F(x)$ ✔️ Even
- $F(x)=|x|$: $F(-x)=|-x|=|x|=F(x)$ ✔️ Even

**Graph property:** Symmetrical about the **y-axis**.

### 6.3 Odd Function

$$f(-x) = -f(x) \quad \text{for every } x \text{ in the domain}$$

**Worked Examples:**

- $f(x)=x^3$: $f(-x)=(-x)^3=-x^3=-f(x)$ ✔️ Odd
- $f(x)=\sin x$: $f(-x)=\sin(-x)=-\sin x=-f(x)$ ✔️ Odd

**Graph property:** Symmetrical about the **origin**.

**⚠️ A function can be neither even nor odd** (most functions fall in this category) — e.g., the Greatest Integer Function is neither.

### 6.4 Greatest Integer Function (Step Function)

$$f(x) = [x] = \text{the greatest integer LESS THAN OR EQUAL TO } x$$

**Worked table:** $[x]=1$ for $1\leq x<2$; $\ [x]=2$ for $2\leq x<3$; $\ [x]=0$ for $0\leq x<1$; $\ [x]=-1$ for $-1\leq x<0$

**Domain:** $\mathbb{R}$ (all real numbers). **Range:** $\mathbb{Z}$ (the set of integers). Graph looks like ascending "steps".

### 6.5 Polynomial Function

Any function of the form $f(x) = a_nx^n + \dots + a_1x + a_0$.

**Examples:** $f(x)=3x^2-4x-2$, $\ f(x)=x^3-5x^2-x+5$, $\ f(x)=3$ (a constant is also a polynomial function, of degree 0).

### 6.6 Rational Function

$$f(x) = \frac{g(x)}{h(x)}, \quad \text{where } h(x)\neq 0 \text{ and } g(x), h(x) \text{ are polynomials}$$

**Example:** $f(x)=\dfrac{x^2-4}{x+1},\ x\neq -1$

### 6.7 Reciprocal Function

$$y = \frac{1}{x}, \quad x\neq 0$$

### 6.8 Exponential Function

$$f(x) = a^x, \quad a>0,\ a\neq 1$$

The special base $e \approx 2.71828$ (an irrational number between 2 and 3) gives $f(x)=e^x$, defined via the infinite series: $$e^x = 1+\frac{x}{1!}+\frac{x^2}{2!}+\frac{x^3}{3!}+\dots$$

**Key graph facts for $y=e^x$ (and similarly $y=a^x$ for $a>1$):**

- As $x$ increases, $y$ increases very rapidly.
- As $x$ decreases, $y$ approaches (but never touches) 0.
- No x-intercept (since $e^x\neq0$ for any $x$).
- y-intercept is always 1 (since $e^0=1$).

### 6.9 Logarithmic Function

$y=e^x$ and $y=\log_e x$ (written simply $\log x$ when base is $e$) are **inverse functions** of each other. Their graphs are symmetric about the line $y=x$.

**Laws of logarithms (parallel to laws of indices):** $$\log_a(mn)=\log_a m+\log_a n \qquad \log_a\left(\frac{m}{n}\right)=\log_a m-\log_a n$$ $$\log_a(m^n)=n\log_a m \qquad \log_b m = \frac{\log_a m}{\log_a b} \text{ or } \log_b m = \log_a m \cdot \log_b a$$

### 6.10 Identity Function

$$f(x) = x \quad \text{for each } x\in\mathbb{R}$$

Domain = Range = $\mathbb{R}$. Graph is a straight line through the origin at 45°.

### 6.11 Constant Function

$$f(x) = c \quad \text{(c is a fixed constant) for every } x\in\mathbb{R}$$

Domain = $\mathbb{R}$, Range = ${c}$ (just one value!). Graph is a horizontal line parallel to the x-axis.

### 6.12 Signum Function

$$f(x) = \begin{cases} 1 & \text{if } x>0 \ 0 & \text{if } x=0 \ -1 & \text{if } x<0 \end{cases}$$

Domain = $\mathbb{R}$. Range = ${-1,0,1}$ (only three possible outputs).

### 6.13 Special Functions — Master Summary Table

| Function         | Formula                 | Domain           | Range                        |
| ---------------- | ----------------------- | ---------------- | ---------------------------- |
| Identity         | $f(x)=x$                | $\mathbb{R}$     | $\mathbb{R}$                 |
| Constant         | $f(x)=c$                | $\mathbb{R}$     | ${c}$                        |

## 🔷 SECTION 7: ALGEBRA OF FUNCTIONS (SUM, DIFFERENCE, PRODUCT, QUOTIENT)

For two real functions $f:X\to\mathbb{R}$ and $g:X\to\mathbb{R}$, where $X\subset\mathbb{R}$:

### 7.1 Sum

$$(f+g)(x) = f(x)+g(x), \quad \text{for all } x\in X$$

### 7.2 Difference

$$(f-g)(x) = f(x)-g(x), \quad \text{for all } x\in X$$

### 7.3 Product

$$(fg)(x) = f(x)\cdot g(x), \quad \text{for all } x\in X$$

### 7.4 Quotient

$$\left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)}, \quad \text{provided } g(x)\neq0,\ x\in X$$

> ⚠️ **The quotient formula ALWAYS needs a domain restriction excluding wherever $g(x)=0$** — this is on top of any restrictions $f$ or $g$ individually had.

**Worked Example:** $f(x)=x^2,\ g(x)=2x+1$ $(f+g)(x) = x^2+2x+1$ $(f-g)(x) = x^2-(2x+1) = x^2-2x-1$ $(fg)(x) = x^2(2x+1) = 2x^3+x^2$ $\left(\dfrac{f}{g}\right)(x) = \dfrac{x^2}{2x+1},\quad x\neq-\dfrac{1}{2}$

**Worked Example (with a root):** $f(x)=\sqrt{x},\ g(x)=x$ (domain: non-negative reals) $(f+g)(x) = \sqrt{x}+x$ $(f-g)(x) = \sqrt{x}-x$ $(fg)(x) = \sqrt{x}\cdot x = x^{3/2}$ $\left(\dfrac{f}{g}\right)(x) = \dfrac{\sqrt{x}}{x} = x^{-1/2},\quad x\neq0$

### 7.5 Algebra of Functions — Quick-Reference Table

|Operation|Formula|Extra Domain Restriction|
|---|---|---|
|Sum|$(f+g)(x)=f(x)+g(x)$|None beyond $f,g$'s own domains|
|Difference|$(f-g)(x)=f(x)-g(x)$|None beyond $f,g$'s own domains|
|Product|$(fg)(x)=f(x)\cdot g(x)$|None beyond $f,g$'s own domains|
|Quotient|$(f/g)(x)=f(x)/g(x)$|Must additionally exclude $g(x)=0$|

## 🔷 SECTION 8: TRICKY EXAM EDGE CASES

### 8.1 Relation vs. Function — The Core Test

Every function IS a relation, but not every relation is a function. The extra requirements that upgrade a relation into a function:

|Check|Relation (general)|Function (special/strict relation)|
|---|---|---|
|Every element of A has an image?|Not required|**Required**|
|Each element of A has only ONE image?|Not required (can have many)|**Required (exactly one)**|

**Worked contrast:** $R={(1,x),(1,y),(2,x)}$ is a perfectly valid **relation**, but it is **NOT a function**, because $1$ maps to both $x$ and $y$ (violates uniqueness).

### 8.2 Domain of A vs. Domain of the Relation — The Silent Killer

When checking whether a relation qualifies as a function on a specific set $A$, always verify the **domain of the relation actually equals $A$ exactly** — not a subset of it.

**Worked Example:** $A={1,2,3,4}$, relation $={(2,\frac12),(3,\frac13),(4,\frac14)}$ Even though each element that DOES appear has a unique image, the element $1\in A$ has **no image at all**. **NOT a function** — a very easy trap to miss if you only check for "repeats" and forget to check "is anything missing?"

### 8.3 Domain of $\sqrt{}$-type vs. $\dfrac{1}{\sqrt{}}$-type — Bracket Trap

For $y=\sqrt{x-a}$: boundary point $x=a$ is **included** (square bracket) since $\sqrt{0}=0$ is valid. For $y=\dfrac{1}{\sqrt{x-a}}$: boundary point $x=a$ is **excluded** (round bracket) since it would make the denominator zero.

**This single-bracket difference is one of the most commonly missed exam details.**

### 8.4 "One Zone" vs. "Two Separate Zones" in Domain/Range Answers

When solving a product-of-two-factors inequality via zone-testing, the answer is **NOT always** a single continuous interval — sometimes the valid zones are the two OUTER regions, giving a domain/range split into two disjoint pieces joined by "$\cup$". **Always test every zone — never assume the pattern from a similar-looking previous question.**

### 8.5 Co-domain ≠ Range (Always Double-Check)

Co-domain is the _entire target set given in the problem_; Range is _only the values that actually get hit_. They can be equal, but are NOT required to be. Always compute Range by looking at which elements of $B$ actually appear as second coordinates — do not just copy the given co-domain.

## 🔷 SECTION 10: COMMON MISTAKES CHECKLIST

- ❌ Do NOT forget to check BOTH function conditions — "every element has an image" AND "no element repeats with different images." Missing either one is a common silent error.
- ❌ Do NOT confuse Range with Co-domain — Range is what's actually HIT; Co-domain is the whole target set given.
- ❌ Do NOT assume $A\times B = B\times A$ — order matters, they are generally different sets of ordered pairs.
- ❌ Do NOT use a square bracket $[a,\infty)$ for $y=\dfrac{1}{\sqrt{x-a}}$-type functions — the boundary must be **excluded**, use $(a,\infty)$.
- ❌ Do NOT stop at one test point when zone-testing a product inequality — test ALL zones, since the valid region can be the middle zone OR the two outer zones, depending on the specific factors.
- ❌ Do NOT forget the domain restriction $g(x)\neq0$ when writing $(f/g)(x)$ — always state it explicitly, even if $f$ and $g$ individually had no restrictions.
- ❌ Do NOT compute $(-y)^2$ as $-y$ — squaring a negative always gives a **positive** result: $(-y)^2=y^2$.
- ❌ Do NOT apply the discriminant method to find range unless the function is genuinely rational with $x$ appearing squared — for simple root/shift functions, use the extremes/boundary substitution method instead (it's faster and doesn't need quadratics).
- ❌ Do NOT assume a function that's monotonic on part of its domain is monotonic on the WHOLE domain — always specify the interval (e.g., $x^2$ is only monotonic piecewise, not on all of $\mathbb{R}$).
- ❌ Do NOT mix up even and odd — even ⟶ symmetric about **y-axis**, $F(-x)=F(x)$; odd ⟶ symmetric about **origin**, $f(-x)=-f(x)$.
